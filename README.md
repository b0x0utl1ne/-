# CET-6 12套一卷语境词书

近 12 次英语六级考试“第1套”的真题语境词书。目标不是把 54,000 多个词排成字母表，而是用 700 个核心词 + 原文句子 + 间隔复习，把词放回六级阅读和听力里。

## 现在就能用

最省事：直接双击根目录的 **`CET6-词书.html`**。它是单文件版，CSS、JavaScript 和全部词书数据都已内嵌，不需要启动服务器。
学习记录与浏览器和文件路径有关；移动文件、换浏览器或清理缓存前，先在「数据 → 导出备份」保存 JSON。

如果浏览器对 `file://` 本地存储限制较多，再用服务器版：

```bash
cd /home/wsa/英语六级学习
./start.sh
```

浏览器打开 `http://127.0.0.1:8765/`。`start.sh` 会优先用 Edge 打开。

也可以直接打开 `site/index.html`，但建议用本地服务器，浏览器本地记录更稳定。

## 内容

- 12 次第1套：2026-06、2025-12、2025-06、2024-12、2024-06、2023-12、2023-06、2023-03（加考）、2022-12、2022-09（加考）、2022-06、2021-12。
- 123 篇成篇文章，54,490 词原文。
- 4,920 个可查词条，全部带音标、中文释义和真题语境。
- 700 个核心词：按 B2/C1、CET6/GRE/TOEFL/IELTS 标签、跨套复现和真题精读“生词推断”综合排序。
- 457 个“精读推荐”词，全部强制进入核心词书；`complacent`、`idolize`、`turmoil`、`scrutinize` 等只出现一次的高价值词不会漏掉。

## 学习闭环

1. **今日**：到期复习 → 今日新词 → 当天真题精读。先做完，再看统计。
2. **词书**：按核心/全部/陌生/熟悉/收藏/精读推荐筛选；每张卡都有音标、释义、原句。
3. **语境**：打开任意一篇原文。单击单词看词卡，右击单词弹出菜单：翻译、熟悉、陌生、收藏、复制、朗读。
4. **复习**：闪卡先回忆再揭晓；按 `1/2/3` 给“忘记/模糊/记得”。答错自动回到 1 天后。
5. **测验**：从真题句子里挖空，四选一；正确/错误会改变词的复习状态。
6. **数据**：导出 JSON 备份、导入、重置；记录只保存在本机 `localStorage`。

右击菜单和状态记录都写进浏览器本地存储，刷新页面不会丢。发音优先使用 Edge 的 Microsoft 自然神经语音：默认 Aria（美音），可在「数据 → 设置」切换 Sonia（英音）或自动。

## 29 天怎么用

考试日期按 [中国教育考试网 2026 年下半年考试公告](https://cet.neea.cn/html1/report/2609/1-1.htm)：**2026-12-12 15:00–17:25**。从 2026-11-13 到 2026-12-11 共 29 个学习日：

- 每天 60–80 分钟：15 分钟到期词 + 25 个新词 + 30–40 分钟真题精读。
- 12 套 × 2 天：A 组听力原文/选词填空，B 组长篇阅读/仔细阅读。
- 每 6 个学习日插入 1 次阶段复习；最后 1 次全真模考、1 天考前轻复习。
- 页面里的“计划”页有逐日任务、文章数和每日新词目标。

详细时间安排见 [`备考计划.md`](./备考计划.md)。

## 数据口径与限制

- 文章原文来自 [懒笔记 CET-6 真题文章](https://english-exam.lazynote.cn/cet6/articles/)；PDF 题干/选项来自 [CET通](https://www.cettong.cn/library/cet6) 作为补充。
- 音标和中文释义来自 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT License。
- `2026-06` 的 PDF 在 CET通 尚未提供，因此该套只用文章页语料；这不影响该套的阅读/听力原文，但不包含该套题干选项的补充词。
- 2022–2023 的若干 PDF 是扫描件，`pdftotext` 只能抽出极少文字；正文覆盖以文章页为准，PDF 只用于可抽取的补充词。
- 文章 token 的 95.2% 可点查；剩下主要是专有名词、缩写、单字母说话人标记（`M`/`W`）和编号。没有为未收录词伪造音标。
- 真题原文版权归全国大学英语四、六级考试委员会；本网页仅用于个人学习。

## 复现与验证

```bash
python3 scripts/fetch_corpus.py
python3 scripts/fetch_reference.py
python3 scripts/fetch_pdfs.py
python3 scripts/build_data.py
python3 scripts/build_site.py
python3 scripts/build_single_html.py
python3 scripts/validate_data.py
node --check site/assets/app.js
```

重建数据还需要系统里的 `pdftotext`（Poppler）和 `python3 -m pip install -r requirements.txt`。

`data/raw/` 是下载缓存，不提交 git；`data/corpus/`、`data/words.json` 和 `site/data.js` 是可复现产物。
`CET6-词书.html` 是面向双击使用的打包产物。
